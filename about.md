This portfolio is a record of my hands-on development in networking, IT support, security, and infrastructure.

My goal is to use each project and lab as evidence of practical skill rather than simply recording that a topic was completed. Git provides the change history, GitHub provides collaboration and remote version control, and GitHub Pages provides a public presentation layer for selected work.

As the portfolio grows, it will include networking labs, diagrams, technical explanations, troubleshooting exercises, configuration examples, and reflections on the technologies used in modern network environments.
