I build systems by learning how the pieces connect.

This portfolio tracks my hands-on development in networking, IT support, infrastructure, security, automation, and technical troubleshooting. I am not using it as a list of completed lessons. I am using it as a working record of what I can actually build, configure, diagnose, document, and improve.

My background is rooted in operations and management, where reliability, process, problem solving, and execution matter. I am applying that same mindset to technology: understand the system, identify the failure point, improve the workflow, and leave behind documentation that makes the next iteration easier.

Git provides the history. GitHub provides the collaboration layer. GitHub Pages turns selected work into a public technical portfolio.

As this site grows, it will include networking labs, configuration examples, diagrams, security exercises, troubleshooting breakdowns, automation experiments, and technical writeups.

The goal is simple: turn learning into capability, and capability into systems that are useful, repeatable, and built to last.
