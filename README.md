# Networking Portfolio

A standalone portfolio for networking, CompTIA Network+ coursework, labs, documentation, and technical blog posts.

## Live Site

GitHub Pages will publish this repository as a Jekyll site.

## Repository Structure

- `_posts/` — technical blog posts
- `labs/` — networking lab documentation and evidence
- `documentation/` — reference notes and technical documentation
- `index.md` — portfolio home page
- `about.md` — portfolio overview
- `_config.yml` — Jekyll/GitHub Pages configuration

## Purpose

This repository is intentionally separate from other GitHub projects so it can serve as a focused networking portfolio and continue growing throughout Network+ training.
